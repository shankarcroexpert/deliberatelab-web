02 — Why we ask where the sale closes

Most tool advisors never ask the one question that matters for you.

Generic "best A/B testing tool" lists rank on features that assume the purchase finishes on the same screen as the test. For a car, a home, a loan or a degree, it doesn't: the decision starts online and closes at a showroom, a branch or a counsellor's call.

That's why question 2 carries real weight here. Answer "mostly offline" and the shortlist tilts hard toward tools built to sit on a data warehouse or run server-side, so a test can be scored against the outcome that actually happened, not a click.
