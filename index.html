05 — Experiments

What an experiment brief actually looks like.

Four illustrative examples of how we frame a test before it's built, not real client results.

Experiment 001 Illustrative example
Problem
High PDP exit rate on mobile before add-to-cart.
Hypothesis
A sticky add-to-cart bar reduces friction for mobile shoppers.
Treatment
Sticky mobile ATC bar with price and size selector.
Primary metric: Add-to-cart rateATC Demo data
Experiment 002 Illustrative example
Problem
Cart abandonment spikes when shipping cost is revealed.
Hypothesis
Surfacing the free-shipping threshold earlier reduces surprise-cost abandonment.
Treatment
A free-shipping progress bar on the cart page.
Primary metric: Cart-to-checkout rateCTC Demo data
Experiment 003 Illustrative example
Problem
Collection-page shoppers bounce without ever filtering.
Hypothesis
Visible filter and sort controls above the fold increase engagement.
Treatment
A sticky filter bar on the collection / PLP.
Primary metric: PLP-to-PDP click-throughCTR Demo data
Experiment 004 Illustrative example
Problem
First-time visitors hesitate to trust an unfamiliar DTC brand at checkout.
Hypothesis
Trust badges and a review count near the buy box increase checkout starts.
Treatment
A trust strip added to the PDP buy box.
Primary metric: PDP-to-checkout rateCVR Demo data
